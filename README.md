# Launch Args Scanner

WinUI 3 приложение: сканирует файлы игры и вытаскивает параметры запуска, которые она проверяет.

## Возможности

### Точно из кода — главный режим
По умолчанию показываются только параметры, подтверждённые дизассемблером (зелёная метка «Проверено кодом»). Это не вероятность: найдено место, где код игры сам сверяет командную строку с этой строкой. Эвристический поиск строк по умолчанию скрыт (включается переключателем уверенности).

Вытаскиваются:
- **Параметры командной строки.** Строки, которые код передаёт в разборщик (Unreal — `FParse::Param` для флагов, `FParse::Value` для параметров со значением). Различает флаг (`-nosound`) и параметр со значением (`-ResX=1920`).
- **Консольные переменные (CVar) с настоящим описанием.** Движок регистрирует их как `(имя, значение по умолчанию, справка, флаги)` — приложение берёт имя **и текст справки прямо из exe**. Описание реальное, из игры, а не из интернета. CVar добавляется в строку запуска через `-dpcvars=Имя=<значение>`.
- У недокументированных параметров описания в бинарнике нет — приложение честно пишет об этом, а не выдумывает.

Движки: нативные x64 (Unreal, Source, CryEngine). Unity на Mono — логика в управляемом `Assembly-CSharp.dll` (нужен dnSpy). Упакованный exe (Denuvo, VMProtect) разобрать нельзя.

### Что ещё вытаскивается (точно, из кода и файлов)
- **Консольные команды** — с настоящей справкой из exe (как CVar, но действия).
- **Ключи конфигов** — все `[Секции]` и ключи из `.ini` с текущим значением и готовой строкой `-ini:` для переопределения.
- **Карты / уровни** — из распакованных `.umap` (Unreal) и `.bsp` (Source), для `-map=`.
- **Языки сборки**, **зависимости/middleware** (Steam, EOS, DLSS/FSR/XeSS, PhysX, античит EAC/BattlEye) и **сведения о сборке** (разрядность, движок, дата) — из таблицы импорта и заголовка PE.

- **Серверные адреса (категория «Адрес»)** — URL, хосты и IP:порт из строк бинарника. Для перенаправления на приватный сервер при возрождении онлайн-игры.
- **Сетевой стек (категория «Сеть»)** — онлайн-подсистема (Steam/EOS/Null), сетевой драйвер, транспорт, шифрование/сжатие трафика, сокеты — из строк и импорта.
- **Доказательство** — у параметров «Проверено кодом» показывается адрес вызова и кусок дизассемблера (lea строки → call парсера); полностью — во всплывающей подсказке.

Фильтр по категориям справа. Содержимое pak/vpk не вскрывается — карты и конфиги видны у распакованных игр.

### Поиск AES-ключа pak (UE4/UE5)
Ключ зашит в exe россыпью в инструкциях `mov …, imm32` (опкод `C7`). «Найти AES-ключ pak» ищет сигнатуры этих инструкций, собирает ключ по таблице смещений и ранжирует кандидатов по энтропии. **Pak не нужен.** Если рядом есть зашифрованный `.pak`, кандидат дополнительно проверяется расшифровкой индекса и помечается «проверен на pak». Вывод в HEX (UnrealPak `crypto.json`) и base64 (FModel), с запасными кандидатами. Кнопка «Проверить ключ» — вставить уже известный ключ и узнать, зашифрован ли индекс. Не сработает на упакованных exe или при другой версии компилятора/UE (нужна новая сигнатура); IoStore `.utoc` пока не поддерживается.

### Распаковка паков (встроенная)
Вкладка **«Распаковка pak»**: открываешь `.pak`, видишь список файлов (путь, размер, метод сжатия, шифрование) и достаёшь выбранные или все в папку — прямо в приложении, без сторонних программ. AES-ключ подставляется из найденного на «Сканере». После поиска ключа кнопка **«Распаковать паки»** сразу открывает эту вкладку с подставленным ключом и паком.

Формат разборщика портирован из CUE4Parse (индекс pak v8–v11, старый и современный directory index, расшифровка AES-256). Сжатие: **без сжатия и Zlib/Gzip распаковываются**; **Oodle/Zstd/LZ4** требуют нативную библиотеку и помечаются как пропущенные (такие файлы видно в списке, но для них нужен repak/FModel). IoStore (`.utoc`/`.ucas`) и «плоский» directory index новых UE5 — пока не поддержаны.

### Запись в Steam
Определяет AppID игры и кнопкой «В Steam» пишет строку запуска прямо в параметры запуска игры (`localconfig.vdf`). Steam должен быть закрыт; делается резервная копия, структура файла проверяется.
- **Запуск + лог.** Запускает игру с собранной строкой (для Unreal добавляет `-log`) и читает лог, который движок пишет сам. Параметры из записанной командной строки помечаются «Видно при запуске». Только чтение лога — в процесс игры ничего не внедряется. Для онлайн-игр с античитом — на свой риск.

### Поиск строк (как было)
- Определяет движок: Unreal 3/4/5 (версию берёт из строки `++UE5+Release-x.y`), Unity (Mono или IL2CPP, плюс версия), Source, Source 2, Godot, CryEngine.
- Читает все `.exe` и `.dll` игры, а для IL2CPP ещё `global-metadata.dat`. Строки достаёт в ASCII и UTF-16 на любом выравнивании.
- Находит:
  - известные параметры движка, включая «голые» строки без дефиса (так их хранит `FParse::Param` в Unreal);
  - строки-флаги `-x`, `--x`, `+x`;
  - параметры из строк справки (usage) вместе с описанием;
  - параметры вида `Name=` в Unreal;
  - CVar'ы Unreal (опционально).
- Ставит каждому параметру уровень уверенности и показывает файлы, где он найден.
- Пропускает сторонние DLL (CEF, PhysX, рантаймы, античиты), чтобы не было чужих флагов.
- Фильтр, поиск, копирование, экспорт в TXT, CSV и JSON.
- Собирает строку запуска двойным кликом по параметру. Её можно скопировать или сразу запустить игру с ней.
- Вкладка «База параметров» содержит около 170 известных параметров с описаниями на русском.
- Принимает перетаскивание папки или exe прямо в окно.

## Сборка
Нужна Windows 10/11.

**Visual Studio 2022** (17.8 или новее) с нагрузками «.NET desktop development» и «WinUI application development»:
открой `LaunchArgScanner.sln`, выбери конфигурацию `Release | x64` и нажми F5.

**Командная строка** (.NET 8 SDK):
```
dotnet publish LaunchArgScanner/LaunchArgScanner.csproj -c Release -r win-x64 --self-contained true -o out
```
Готовый `out\LaunchArgScanner.exe` запускается без установки.

**GitHub Actions**: если залить проект в репозиторий, `.github/workflows/build.yml` соберёт exe сам.
Результат лежит в Actions, в артефакте `LaunchArgScanner-win-x64`.

## Ограничения
- 100% полный список не гарантирован: часть параметров собирается динамически или читается из конфигов.
- Упакованные exe (Themida, VMProtect, Denuvo) прячут строки, поэтому найдётся меньше.
- Приложение только читает файлы на диске и не трогает процесс игры, так что игры с античитом это не затрагивает.
- Не запускай приложение от администратора: в WinUI 3 тогда не работают диалоги выбора файлов и drag & drop.
